# المصحف المُعلّم — تلاوة متزامنة كلمة بكلمة

مصحف إلكتروني يحاكي **مصحف المدينة النبوية** (نصّ حقيقي قابل للتحديد والنسخ، بلا صور،
بنفس تقطيع الصفحات: ٦٠٤ صفحة × ١٥ سطراً)، مع متابعة التلاوة من ملف `timings.db`:

* الآية الجارية **تُلَوَّن بالأخضر**، والكلمة المنطوقة **بالأحمر**.
* تشغيل MP3 من **رابط مباشر** (من جدول `surah_list`)، أو **تنزيله** للتشغيل بلا إنترنت،
  أو تشغيل **ملف محلي** من جهازك.
* قلب الصفحة تلقائياً مع التلاوة، أو تصفّح حر مع زر «متابعة التلاوة».

رسم المصحف مبني على قاعدة بيانات مكتبة [quran-madina-html](https://github.com/tarekeldeeb/quran-madina-html)
(نصّ حقيقي، أي خط تختاره) — محمّلة محلياً داخل المشروع. **لا يحتاج إنترنت إطلاقاً**.

---

## ١) التشغيل

### الطريقة الأسهل — ملف واحد
افتح **`quran-mushaf-standalone.html`** (في مجلد المشروع أو بجواره) بنقرتين.
كل شيء مضمّن داخله: الرسم، الخطوط، محرّك SQLite. يعمل بدون سيرفر وبدون إنترنت.

### الطريقة الأفضل للتطوير — سيرفر محلي
```bash
cd quran-mushaf
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

> النسخة المعيارية (index.html) تحمّل الأصول من مجلدات `assets/` و `src/`،
> فتحتاج سيرفراً بسيطاً؛ أما نسخة الملف الواحد فتعمل من `file://` مباشرة.

---

## ٢) الاستخدام في ثلاث خطوات

1. **قاعدة التوقيت**: اضغط *قاعدة التوقيت* واختر ملف `timings.db`
   (يمكنك أيضاً سحب الملف وإفلاته في أي مكان في النافذة).
   يقرأ البرنامج المخطط تلقائياً ويعرض ملخص المطابقة في تبويب *الإعدادات*.
2. **اختر سورة** من تبويب *السور*: ▶ تشغيل مباشر من الرابط، ⬇ تنزيل الملف، 📖 الانتقال لصفحتها.
   أو شغّل **ملف MP3 من جهازك** بزر *ملف محلي* (يُطابق السورة من رقم في اسم الملف إن وُجد).
3. **تابع**: الآية خضراء والكلمة حمراء. انقر أي كلمة للانتقال إليها، واستخدم شريط
   *المعايرة* إن سبق التلوين أو تأخر عن الصوت.

## ٣) بنية قاعدة التوقيت المدعومة

البرنامج يكتشف الجداول والأعمدة **تلقائياً** بالاسم، وإن لم ينجح يفتح نافذة
*مطابقة الأعمدة* لتختارها يدوياً (مع معاينة لعيّنة من البيانات).

الشكل المعتاد:

```sql
CREATE TABLE surah_list (          -- اختياري: روابط الصوت
  id      INTEGER PRIMARY KEY,
  sura_no INTEGER,                 -- أو: surah_no / surah / chapter
  name    TEXT,                    -- اسم السورة (اختياري)
  url     TEXT,                    -- رابط MP3 (أو: link / mp3 / file / path / audio)
  reciter TEXT                     -- اختياري
);

CREATE TABLE segments (            -- المقاطع (الأساسية)
  sura_no    INTEGER,              -- أو: sura / surah_id ...
  aya_no     INTEGER,              -- أو: aya / ayah / verse
  word_no    INTEGER,              -- اختياري: ترتيب الكلمة في الآية
  start_ms   INTEGER,              -- أو: start_time / begin / from
  end_ms     INTEGER               -- أو: end_time / to
);
```

### الشكل المضغوط (المستخدم في قواعد كثيرة)

```sql
CREATE TABLE segments(
  surah_number  INTEGER,
  ayah_number   INTEGER,
  duration_sec  INTEGER,
  timestamp_from INTEGER,   -- بداية الآية (ميلي ثانية)
  timestamp_to   INTEGER,   -- نهاية الآية
  segments       TEXT       -- [[رقم_الكلمة, بداية_الكلمة, نهاية_الكلمة], ...]
);
-- مثال صف:
-- 1 | 1 | 4 | 20 | 4750 | [[1,150,640],[2,640,1380],[3,1380,2600],[4,2600,4750]]
```

هذا الشكل **مدعوم مباشرة**: يُقرأ عمود `segments` ويُفكّ إلى توقيت لكل كلمة،
وتُستخدم `timestamp_from`/`timestamp_to` لحدود الآية عند غياب المقاطع.

### توقيت البسملة (`ayah_number = 0`)

صفوف البسملة برقم آية **صفر** تُقرأ وتُستخدم لتلوين **كلمات البسملة الأربع كلمة بكلمة**
في كل سورة (٢→١١٤؛ سورة التوبة ٩ ليس لها بسملة)، بدل تركها بلا تلوين أو ضمّها للآية ١:

```sql
-- surah_number | ayah_number | duration_sec | timestamp_from | timestamp_to | segments
   2            | 0           | 4            | 100            | 5080         | [[1,350,870],[2,870,1650],[3,1650,2860],[4,2860,5080]]
```

فتُلوَّن `بِسْمِ` ← `ٱللَّهِ` ← `ٱلرَّحْمَـٰنِ` ← `ٱلرَّحِيمِ` بأزمنة ٣٥٠/٨٧٠/١٦٥٠/٢٨٦٠،
وتُضاء البسملة كلها كلون آية واحد، ثم ينتقل التلوين إلى الآية ١ عند ٥٥٨٥.
ويظهر في الشريط: «سورة البقرة — البسملة • كلمة ٢».

> **حماية آية ١:** إن كانت قاعدتك فيها صفوف بسملة صريحة (رقم آية = ٠) فالبرنامج يتجاهل
> خيار «احتواء البسملة في الآية 1» **لهذه السورة بالذات**، فلا تُنقل كلمة «الٓمٓ» (الآية ١)
> إلى البسملة. القرار يُتخذ **لكل سورة على حدة**: سورة بصفوف آية ٠ ← النمط A، وسورة بلا صفوف
> آية ٠ ← النمط المكتشَف (أو المفروض) من الإعدادات.
عيّنة جاهزة بهذا المخطط: `samples/timings-segments.db`
(بيانات السور ١–٣ حقيقية وباقي السور تقديرية)، ومولّدها `tools/make_db_from_segments.py`.
ولتحويل ملف `segments.json` (سطر لكل آية) إلى قاعدة بنفس المخطط:
`python3 tools/make_db_from_json.py segments.json samples/my-timings.db --reciter '…'`.

#### قراءة توقيت **الكلمات** من عمود `segments` (Round ٢١)

البرنامج يقرأ عمود المقاطع المضغوط `[[رقم الكلمة، من، إلى], …]` بصيغه كلها، ولا يكتفي
بأول خمسة صفوف من الجدول (كثير من القواعد تبدأ صفوفَ بلا مقاطع — رأس سورة أو بسملة —
فيفوت الكشف وتُضاء الآية كلها بدل كلماتها):

| الصيغة في العمود | الحالة |
|---|---|
| `[[1,13400,14240],[2,14240,15070]]` (نص) | ✓ |
| `[[1,13400,14240], …]` مخزّنة **BLOB** (بايتات) | ✓ يُفكّ ترميزها |
| بأقباس مفردة أو مسافات/أسطر زائدة: `[[1,'13400','14240'], …]` | ✓ |
| نص `1:13400:14240,2:14240:15070` | ✓ |
| أزواج فقط `[[13400,14240], …]` (بلا أرقام كلمات) | ✓ تُرقَّم بترتيب الورود |
| كائن `{"words":[[1,13400,14240]]}` أو `[{word,start,end}]` | ✓ |
| `NULL`/`''` في بعض الصفوف | تُقرأ تلك الصفوف بتوقيت الآية، والبقية بالكلمات |
| الصفوف الأولى بلا مقاطع | ✓ الفحص على ١٥٠ صفاً لا على خمسة |
| جدول الكلمات منفصل (`words`) عن `segments` | ✓ ينتقل البرنامج إليه تلقائياً |

ولو فُهم العمود لكنه لم يُفلَح، يكتب في لوحة «مطابقة الأعمدة» مثالاً من نصّه (٦٠ حرفاً)
لتبيان الصيغة. ويظهر في اللوحة نفسها سطر **«توقيت الكلمات: N مقطع كلمة»** — أو
«لا يوجد — قُرئ توقيت الآية فقط» — فهو الدليل على أن التلوين كلمة بكلمة لا آية بأكملها.

**الإعداد الجديد**: «ترقيم آيات ملف التوقيت» في مجموعة *التوقيت* — `تلقائي` (افتراضي) /
`ورش — حوِّل الأرقام إلى مفاتيح المصحف` / `حفص — لا تحوِّل`. يُطبَّق فوراً على القاعدة
المحمّلة، ويُنفع إن كان ترقيم ملفك لا يشبه كليهما أو أردت تجاوز الكشف التلقائي.

ما يتعامل معه البرنامج تلقائياً:

| الحالة | المعالجة |
|---|---|
| أسماء أعمدة مختلفة (`surah_id`, `verse`, `t0/t1` …) | مطابقة بالاسم، ونافذة يدوية عند الحاجة |
| **ثانية** بدل ميلي ثانية | تُكتشف من متوسط أطوال المقاطع (ويمكن فرضها) |
| ترقيم الكلمات يبدأ من **0** أو **1** | يُكتشف تلقائياً |
| **البسملة** محسوبة ضمن الآية 1 أو مستقلة (`aya = 0`) أو غائبة | تُكتشف لكل سورة (النمط A/B) ويمكن فرضها |
| رقم السورة مفتاح أجنبي لجدول `surah_list` | يُحوَّل عبر الجدول |
| **لا يوجد عمود كلمة** (توقيت على مستوى الآية) | تُوزَّع أزمنة الآية على كلماتها تقديرياً، مع تنبيه |
| عمود مضغوط `word_index:start:end` مفصول بفواصل | يُفكّ تلقائياً |
| **عمود مصفوفة JSON** `[[1,150,640],[2,640,1380]]` | يُفكّ تلقائياً (صيغتك) |
| تكرار رقم كلمة داخل الآية (ضجيج في المحاذاة) | يُحتفظ بآخر ورود لكل كلمة |
| **ترقيم الآيات على رواية أخرى** (ورش ↔ حفص، فرق في ٦٠ سورة) | يُكتشف من عدد كلمات كل آية (أو عدد آيات كل سورة)، ويُحوَّل تلقائياً إن طابق المصحف، وإلا يظهر **تنبيه** مع زر التبديل |

> ترقيم الكلمات الافتراضي = عدد كلمات رسم المصحف (٧٧٬٤٣٤ كلمة + البسملات)،
> وهو العدّ المعتمد في أغلب قواعد التوقيت.

### عيّنة للتجربة
`samples/timings-sample.db` مولّدة بـ `tools/make_sample_db.py` — أزمنتها **تقديرية**
(ليست توقيتاً حقيقياً) والغرض منها تجربة الواجهة فقط. استبدلها بملفك.

## ٤) المزايا

**المصحف**
* رسم مصحف المدينة: ٦٠٤ صفحة، تقطيع السطور والتسطير والمطّ (kashida) كما في المطبوع.
* **اسم السورة داخل زخرفتها** أعلى الصفحة **موسّطاً تماماً وبخط المصحف نفسه وبالتشكيل الكامل**
  (سُورَةُ ٱلْبَقَرَةِ) — جدول الأسماء في `tools/sura_names.py`.
  و**أرقام الآيات داخل زخرفة ذهبية** كما في المصحف المطبوع.
* **تنقّل سريع بالنقر داخل الصفحة**:
  * **اسم السورة** (أعلى الصفحة) → قائمة **١١٤ سورة** فيها بحث؛ اختيار أي سورة يذهب إليها **ويشغّلها**.
  * **رقم الجزء** → شبكة **٣٠ جزءاً** → أول صفحة الجزء.
  * **رقم الصفحة** (أسفل الصفحة) → حقل إدخال + شبكة **٦٠٤ صفحة** → الانتقال فوراً.
* **في وضع إخفاء الواجهة**: أي نقرة على صفحة المصحف **تُظهر شريط التحكم بالصوت** ٥ ثوان ثم يختفي تلقائياً.
* **أسهم تقليب الصفحة (→ ←) تبقى عاملة في وضع إخفاء الواجهة** — باهتة جداً (١٣٪) حتى لا تشوّش
  على القراءة، وتظهر كاملة عند مرور المؤشر أو لمسها.
* **ملف الإعدادات**: زرّا **حفظ الإعدادات في ملف** و**استيرادها من ملف** (`mushaf-settings.json`)
  في تبويب الإعدادات — لنقل كل الإعدادات (الطبعة، الخط، الزخرفة، الألوان، الصفحة…) بين الأجهزة.
* **شدّة البسملة عند حفص**: في سورتي **التين (٩٥) والقدر (٩٧)** تبدأ البسملة بشدّة فوق الباء
  «**بِّسْمِ**» (كانت البيانات تفتقدها فأُضيفت: `ب + ّ + ِ`)، وبقية السور «بِسْمِ» بلا شدّة.
* **زر إخفاء شريط التشغيل** (⌄ أعلى يسار الشريط): يُخفي الشريط وحده ويمنح المصحف ارتفاعه كاملاً،
  ويظهر زر عائم (⌃ أسفل اليمين) لإرجاعه. والحالة **محفوظة** بين الجلسات.
* **زر الإعدادات السريع** (⚙ بجانب زر إخفاء الواجهة في الشريط العلوي): يفتح تبويب
  **الإعدادات** مباشرة بدل فتح قائمة السور ثم النقر على التبويب.
* **متابعة التشغيل إلى السورة التالية**: خيار في تبويب الإعدادات — عند انتهاء السورة ينتقل
  تلقائياً إلى السورة التي بعدها ويشغّلها (ويتوقّف عند ١١٤). **مُعطّل افتراضياً** حتى لا يفاجئك الانتقال.
* **في وضع إخفاء الواجهة يظهر شريط عائم صغير** في أسفل الشاشة فيه زرّان متجاوران:
  **⚙ الإعدادات** و**👁 إظهار الواجهة** — فتصل إلى الإعدادات أثناء القراءة بلا إظهار الشريطين
  (الدرج يُفتح على تبويب الإعدادات مباشرة فوق الصفحة).
* **زر إخفاء الواجهة** (👁 في الشريط العلوي، أو `H`): يُخفي الشريطين والشارات وأسهم التنقّل، ويدخل
  ملء الشاشة، ويضبط **أكبر تكبير يملأ الشاشة بلا تمرير** آلياً (يُعاد التكبير السابق عند الإظهار،
  و`Esc` أو الزر العائم للإرجاع). والمسرح يغطّي الشاشة كاملة (`inset:0`) فلا يبقى فراغ في الأعلى،
  ويُحسب التكبير **بعد استقرار التخطيط** (إطارين) وبحسم حشو المسرح، فيهامش ٨–١٠px فقط حول الصفحة.
* **التسطير للتجويد**: عند تشغيل «أحكام ملوّنة» يصير تمييز الآية والكلمة **تسطيراً** (أخضر ٢px /
  أحمر ٣px) بدل لون الخط أو الخلفية، فتبقى ألوان الأحكام سليمة؛ وعند **إيقافها يرجع تلقائياً إلى
  تلوين الخط**. الأنماط الأخرى (لون الخط، الخلفية، الاثنان) لم تتغيّر.
* **رقم الصفحة في أسفل الصفحة** (كما في المصحف) وهو **قابل للنقر**.
* **طبعتان**: ١٤٠٥ و١٤٣٩ — الافتراضي **١٤٣٩** (انظر القسم ٧).
* **روايتان**: **حفص عن عاصم** (الافتراضي) و**ورش عن نافع** — من قائمة «الرواية» في الإعدادات.
  * **المصدر**: `uploads/words_warsh.json` — نصّ مصحف ورش **كلمة بكلمة** (٧٧٤٢٦ كلمة مع
    `surah_num` و`ayah_num` و`page_num` و`word_num` والرسم `ayah_uthmani`)،
    ومولّد الملف `tools/make_warsh.py`.
  * **المحاذاة كلمة بكلمة** (لا بأرقام الآيات): ترقيم الآيات يختلف بين الروايتين في **٥٢ سورة**
    (العدّ المدني ٦٢١٤ آية مقابل الكوفي ٦٢٣٦)، فتُحاذى كلمات كل سورة بمطابقة هيكل الكلمة
    بعد تجريد التشكيل (`difflib`). النتيجة: **٧٧٨٧٨ من ٧٧٨٨١ كلمة (١٠٠٪)** لها مقابل عند ورش.
  * **التخطيط والتوقيت نفسيهما**: تُستبدل الكلمة في مكانها، فلا تتغيّر الصفحات ولا السطور ولا
    أزمنة التوقيت ولا أرقام المفاتيح `س:آ:ك`.
  * **ملفات توقيت مرقّمة على ورش (Round ٢١)**: عند تحميل `timings.db` يُقارَن **أعلى رقم كلمة
    في كل آية** بعدّها المتوقع في كل رواية، فيُعرَف ترقيم الملف. عيّنة المستخدم الحقيقية
    طابقت عدّ ورش في **٦٢٠٩ من ٦٢١١ آية** وعدّ حفص في ٣٥٢٤ فقط. وإن كان الملف على ورش والمصحف
    على ورش حُوِّل كل مقطع إلى مفاتيح المصحف الداخلية بجدول `tinv` المولَّد مع `assets/warsh.json`
    (**٦٠ سورة، ٢٨٩٧ آية**)؛ وهو يعالج الحالتين معاً: آية ورش الممتدة على آيتَي حفص
    («أَلَٓمِّٓ + ذَٰلِكَ ٱلْكِتَـٰبُ…» = ورش ١ من البقرة) تُقسَّم على الآيتين، وآية حفص المقسومة
    عند ورش (الفاتحة ٧ = ورش ٦ + ٧) تُحمَل بإزاحة كلمات. بعدها يعمل التلوين والتنقّل والشريط
    كما في حفص بالضبط، لأن كل شيء مثبَّت على المفتاح نفسه `س:آ:ك`.
  * **تنبيه عند اختلاف الروايتين**: إن اختار المستخدم مصحف **ورش** ورفع توقيتاً على ترقيم **حفص**
    (أو بالعكس) ظهرت نافذة تنبهه وتخيره بين «تبديل المصحف إلى …» (يُعاد تطبيق التوقيت فوراً)
    و«اختيار ملف توقيت …» و«متابعة بلا تغيير» — ولا يُحذف من توقيته شيء.
  * **الترجيح الأخير بمقياس الرسم لا بالأرقام**: يُعدّ كم مقطعاً يقع خارج كلمات آيته «كما هو»
    و«لو حُوِّل إلى ورش»؛ التفسير الذي يبقي المقاطع داخل رسم المصحف هو المعتمد
    (عيّنة المستخدم: ٨٣١ مقطعاً خارج رسم المصحف كما هي، مقابل **٠** بعد التحويل — من ٦١٦٠ مقطعاً مفحوصاً).
    وبذلك لا يعتمد الكشف على تطابق الترقيم مع عدّ حفص حرفياً.
  * الملفات التي **بلا توقيت كلمات** (توقيت آية فقط) تُكشف بعدد آيات كل سورة (١١٤ سورة:
    ١١٤ تطابق ورش مقابل ٦٤ لحفص)، ويُقسَّم زمن آية ورش على آيات حفص التي تغطّيه بنسبة كلماتها.
  * عيّنة للتجربة: `samples/timings-warsh-segments.db` (بُنيَت من `uploads/segments.json`
    بـ `tools/make_db_from_json.py`، وهو يحوّل أي JSON بنفس الشكل إلى قاعدة SQLite بالمخطط نفسه).
  * **أرقام الآيات تُترجم تلقائياً**: زخرفة نهاية الآية تُظهر **رقم ورش** (الفاتحة: ١…٧ بدل ٢…٧،
    والبقرة: لا زخرفة بعد «الم» لأنّ آية ورش ١ تمتدّ إلى «للمتقين»). وكل آية ورش لها زخرفة
    واحدة بالضبط — **٠ ناقصة و٠ زائدة** من ٦٢١٤؛ و٥٨ زخرفة **داخلية** تُضاف في وسط آية حفص
    حيث تنتهي آية ورش (مثل الفاتحة: ٦ بعد «أنعمت عليهم»). وحيث تستمرّ آية ورش عبر حدّ آية حفص،
    **لا تُرسم زخرفة** كما في المصحف.
  * فروق القراءة ظاهرة فعلاً: `مَـٰلِكِ` ← `مَلِكِ` (١:٤)، `يَخۡدَعُونَ` ← `يُخَـٰدِعُونَ` (٢:٩)،
    `وَوَصَّىٰ` ← `وَأَوۡص۪ىٰ` (٢:١٣٢)، والرسم المغربي (`اِ۬لْحَمْدُ`، `فِے`، `ءَامَنُواْ`).
  * البسملة غير معدودة في بيانات ورش، فتُولَّد من صورها الواردة: «بِسْمِ اِ۬للَّهِ اِ۬لرَّحۡمَـٰنِ اِ۬لرَّحِيمِ».
    وفي **أربع سور تنتهي بسملتها بعلامة الوقف ۖ**: القيامة والمطفّفين والبلد والهمزة
    («…اِ۬لرَّحِيمِۖ») كما في مصحف ورش.
    و**علامة الوقف ۖ محفوظة بالكامل** (٩٩٥١ موضعاً) ولا تُحذف — فالنصّ القرآني وما فيه من
    علامات لا يُتصرَّف فيه: خط «مجمع الملك فهد» (Hafs) يضعها فوق الحرف بلا عرض إضافي (وهو
    الأحسن)، وإن لم يفعل الخط ذلك رُسمت كـ«ص» صغيرة فوق السطر تلقائياً (`span.waqf`).
  * **تلوين التجويد يُعطَّل تلقائياً** مع ورش (قواعده محسوبة على نصّ حفص).
  * حرف `ے` (U+06D2) غير موجود في الخطوط، فيُحوَّل إلى `ي` عند العرض.
  (يزيل واصل الكلمات والفراغ الشعري اللذين يقطعان الكلمة، ويفصل البسملة إلى مفتاح ٠).
* **الجوال**: يُفتتح تلقائياً على **صفحة واحدة** (بدل الوجه المزدوج) على الشاشات الضيقة (≤٥٦٠px)
  أو عند أول تشغيل من جوال — ويمكن إرجاع الوجه يدوياً من الإعدادات. سطح المكتب يبقى صفحتين.
* **الصفحتان الافتتاحيتان**: **زخرفة واحدة فقط** في صفحة الفاتحة وصفحة بداية البقرة — وهي زخرفة
  سطر اسم السورة (سُورَةُ ٱلْفَاتِحَةِ / سُورَةُ ٱلْبَقَرَةِ)، بلا زخرفة رأس إضافية فوقها؛
  ويُوزَّع الفراغ **نصفين متساويين فوق النص وتحته** فيصير النص في **وسط الصفحة** تماماً
  (١١٥px فوق ومثلها تحت) كما في الطبعة. التنسيق متطابق في الصفحتين.
* **الشكل البيضاوي للصفحتين ١ و٢ (طبعة ١٤٣٩)**: سطور هاتين الصفحتين **موسّطة بعروضها الطبيعية**
  (لا تُمدّ إلى الطرفين كباقي الصفحات)، ويُقرَّب كل سطر من عرض يتبع **قوس دائرة** — قصير في الأطراف
  وأطول في الوسط — بفراغات بين الكلمات فقط، ثم تكبير موحّد لكل السطور يحفظ نسبها. النتيجة كتلة نصّ
  **بيضاوية/دائرية كما في المصحف المطبوع**: أعراض السطور (نسبةً لعرض الصفحة)
  ص١: `٠٫٦٧، ٠٫٦٧، ٠٫٩٨، ٠٫٨٢، ٠٫٩٨، ٠٫٦٦، ٠٫٣٨` — ص٢: `٠٫٤٩، ٠٫٩٤، ٠٫٩٧، ٠٫٩٨، ٠٫٩٧، ٠٫٩٧، ٠٫٣٧`
  وكل سطر متوسّط تماماً (انحراف المركز ٠). **ويُطبَّق في الطبعتين (١٤٠٥ و١٤٣٩) ومع الروايتين**:
  | | الصفحة ١ | الصفحة ٢ |
  |---|---|---|
  | حفص ١٤٣٩ | `٠٫٦٧ ٠٫٦٧ ٠٫٩٨ ٠٫٨٣ ٠٫٩٨ ٠٫٦٦ ٠٫٣٨` | `٠٫٤٩ ٠٫٩٤ ٠٫٩٧ ٠٫٩٨ ٠٫٩٧ ٠٫٩٧ ٠٫٣٧` |
  | حفص ١٤٠٥ | `٠٫٦٧ ٠٫٦٧ ٠٫٩٨ ٠٫٨٣ ٠٫٩٨ ٠٫٦٦ ٠٫٣٨` | `٠٫٤٩ ٠٫٩٧ ٠٫٩٨ ٠٫٩٨ ٠٫٩٧ ٠٫٩٨ ٠٫٣٧` |
  | ورش ١٤٣٩ | `٠٫٥٩ ٠٫٦٥ ٠٫٩٦ ٠٫٨٣ ٠٫٩٩ ٠٫٧٨ ٠٫٣٨` | `٠٫٤٩ ٠٫٨١ ٠٫٩٧ ٠٫٩٨ ٠٫٩٧ ٠٫٧٥ ٠٫٣٧` |
  والتوسيط تامّ في كل الحالات (انحراف ٠)، ولا سطر يتجاوز الصفحة. هذا مقصود: هما الصفحتان الوحيدتان اللتان لا تُضبطان
  على الطرفين، تَبَعاً للمصحف المطبوع — وبقية الصفحات تبقى مضبوطة (بداية السطر = الحد الأيمن
  ونهايته = الحد الأيسر بفارق ≤ ١px).
* **ضبط السطرين محصّن ضد تحميل الخط المتأخّر**: خطوط المصحف محمّلة بـ `font-display:swap`، فكان النص
  يُقاس بخط بديل عند أول تشغيل (ذاكرة مؤقتة باردة) فيُضبط خطأً ولا يُصحَّح بعد وصول الخط. الآن يُطلب
  الخط صراحةً ويُنتظر قبل الرسم (`preloadFont`)، وتُعاد مطابقة السطور آلياً عند `fonts.ready`/`loadingdone`.
* **الخط الرقمي**: خيار خامس (نسخي) يعرض المصحف بخط نظام عربي عادي مع **إعادة تقطيع السطور بقياس
  فعلي** لكل كلمة، فيبقى عدد السطور وحدود الصفحات الست مئة وأربع كما هي، والضبط تلقائي.
* **زخارف أرقام الآيات**: ٤٧ زخرفة جاهزة لعلامات الآيات (القسم ٨).
* **مصحف التجويد**: تلوين ١٧ حكماً حرفاً بحرف من بيانات quran.com (القسم ٩).
* ٤ خطوط: مجمع الملك فهد (Hafs)، عثماني، أميري، **أميري ملوّن (تجويد)** — هذا الأخير خط
  ألوان (COLR) يلوّن الحروف ذات الأحكام: أحمر وأخضر وبرتقالي وأزرق.
  ومع اختياره يتحوّل التلوين تلقائياً إلى **خلفية خفيفة** حتى تبقى ألوان التجويد ظاهرة.
* فتحة صفحتين (كالمصحف) أو صفحة واحدة، تقريب حتى ٢٢٠٪، وضع ليلي، إطار مزيّن.
* عنوان السورة بإطار مزخرف، رقم الجزء والصفحة، علامات الأجزاء والأحزاب في النصّ.

**المتابعة**
* تلوين الآية (أخضر) والكلمة (أحمر)، بثلاثة أنماط: **لون الخط** (الافتراضي،
  بلا أي تغيير في الخلفية)، أو خلفية الكلمة، أو الاثنان — من تبويب الإعدادات.
* **النقر على أي كلمة في أي صفحة**: إن كانت من **السورة نفسها** انتقل إلى نطقها مباشرة، وإن كانت من
  **سورة أخرى** شغّل تلك السورة (من مجلد الصوت أو رابطها) ثم انتقل إلى الكلمة المنقورة — و**تبقى
  في صفحتك** (لا يقفز إلى أول السورة). وإن لم يكن للسورة صوت تُضاء الكلمة مع تنبيه.
* **تلوين البسملة كلمة بكلمة** من صفوف `ayah_number = 0` (٢→١١٤)، ويُنصّ على ذلك في الشريط: «— البسملة».
* لونا التلوين قابلان للتخصيص، ويمكن إيقاف تلوين الآية أو الكلمة مستقلاً.
* قلب الصفحة تلقائياً، ونقر الكلمة للانتقال إليها.
* **إعادة القراءة مدعومة**: إن أعاد القارئ كلمة أو كلمتين ثم واصل، يتتبّع التطبيق الكلمة
  المعادة ويرجع إليها بالتوقيت الجديد (مثال: ١ ٢ ٣ ٤ ٥ ٦ ← ٥ ٦ ← ٧ ٨ …).
  ويُحذف تلقائياً أي مقطع شارد قبل بداية الآية.
* معايرة زمنية (offset) ±٤ ثوان لحالات سبق/تأخر التوقيت.
* شريط تقدّم عليه علامات الآيات.

**التسميع**
* تكرار: الآية / الكلمة / صفحة المصحف / السورة، مع عدد مرات.
* السرعة من ٠٫٥× إلى ٢×، رجوع ٥ ثوان، تنقّل آية بآية.
* **التكرار يُطبَّق فوراً**: أي تغيير في نمط التكرار (الآية / الكلمة / الصفحة / السورة) أو في
  عدد المرات يبدأ **عدًّا جديداً من بداية الوحدة الحالية** في نفس اللحظة — لا انتظار لانتهاء دورة
  قديمة. وبعد استيفاء العدد **يتوقّف التكرار فعلاً** وترجع القائمة إلى «بدون» (كان يكرّر بلا نهاية).
* زر **الآية السابقة** كأي مشغّل: الضغطة الأولى تُرجع إلى بداية الآية الحالية،
  والثانية إلى الآية التي قبلها.

**الصوت**
* **فتح مجلد الصوت** (زر «فتح مجلد الصوت» في تبويب السور): تختار مجلداً فيه تلاوة كاملة،
  فيُربط كل ملف بسورته تلقائياً ويُستعمل بدل الروابط (بل وبدون قاعدة توقيت للروابط).
  المطابقة تتم بـ:
  | اسم الملف | السورة |
  |---|---|
  | `001.mp3` · `1.mp3` · `١١٠.mp3` | الرقم في أول الاسم (والأرقام العربية مدعومة) |
  | `005 - النساء.mp3` · `سورة ٥.mp3` | أول رقم صحيح (١–١١٤) في الاسم |
  | `البقرة.mp3` · `سورة البقرة - مشاري.mp3` | اسم السورة بعد توحيد الألف والهمزة والتاء والتشكيل |
  | `مقطع غير معروف.mp3` | نافذة **مطابقة يدوية**: قائمة منسدلة بـ ١١٤ سورة لكل ملف |
  والملفات غير الصوتية تُتجاهل، وكل سورة مرتبطة بملف تظهر عليها شارة **«ملف محلي»** في القائمة،
  **ويُلَوَّن اسمها بلون التطبيق** (مع شريط جانبي ملوّن) فتميّز المتوفّر من غيره بنظرة واحدة،
  ويظهر اسم الملف في الشريط أثناء التشغيل (`ملف محلي: 002.mp3`).
* **أولوية مجلد الصوت**: أي سورة لها ملف في المجلد تُشغَّل منه **فوراً**، بلا انتظار الرابط
  وبلا فحصه — حتى لو كان رابطها في القاعدة رابط Google Drive محجوباً (لا يُفتح تبويب ولا تنزيل).
  وتعمل القائمة والقائمة المنسدلة للسور وزر التشغيل كلها بهذه الأولوية، وتعمل حتى **بلا قاعدة
  روابط** أصلاً (توقيت الكلمات يحتاج القاعدة، والتشغيل لا).
* **«متابعة التشغيل إلى السورة التالية»** ينتقل إلى **أول سورة تالية يتوفر لها صوت**
  (ملف في مجلد الصوت أو رابط صالح في القاعدة) — فيتخطّى السور التي لا صوت لها بدل التوقّف عندها.
* تشغيل مباشر من الروابط، أو تنزيلها وتخزينها في المتصفح (IndexedDB) للعمل بلا إنترنت.
* تنزيل كل السور دفعة واحدة، وحفظ الملفات باسم `001-القارئ.mp3`.
* دعم السحب والإفلات لملفات `.db` و `.mp3`.

**الاختصارات**: `مسافة` تشغيل، `←/→` آية، `↑/↓` صفحة، `Shift+←/→` ٥ ثوان،
`R` تكرار الآية، `N` وضع ليلي، `F` ملء الشاشة، `H` إخفاء الواجهة، `S` قائمة السور، `+/-` السرعة.

## ٦) ملاحظات مهمة

* **تنزيل MP3** يحتاج أن يسمح الخادم بـ CORS (`Access-Control-Allow-Origin`)؛
  وإلا يفتح البرنامج الرابط في تبويب جديد. التشغيل المباشر لا يحتاج CORS.
  الملفات المحلية أو المستضافة عندك تعمل تنزيلاً وتخزيناً بشكل كامل.
* ملفات SQLite تُقرأ بالكامل في الذاكرة داخل المتصفح (sql.js/WebAssembly) — الملفات
  الكبيرة (عشرات الميغابايت) تعمل لكنها تستهلك ذاكرة.
* إن أصرّ البرنامج على فتح نافذة المطابقة: راجع اختيار الجدول وعمودي البداية/النهاية،
  ثم اضغط *تطبيق*.

## ٧) طبعة المصحف

يطبع التطبيق الرسم بأسلوب **مصحف المدينة النبوية** ويدعم طبعتين (الإعدادات → طبعة المصحف):

|---|---|---|
| **١٤٠٥هـ** (الافتراضي) | قاعدة `Madina05-*` من مكتبة quran-madina-html | تقطيع السطور والتسطير كما تولّده المكتبة |
| **١٤٣٩هـ** | `assets/layout-1439.json` — توزيع السطور والصفحات لطبعة ١٤٣٩ (رسم QCF V2 كما تنشره Quran.com) | **النصّ الحقيقي محفوظ**: البحث والنسخ والتلوين والتوقيت تعمل كما هي |

ملف التوزيع مولّد بـ `tools/make_layout_1439.py`: يحاذي تسلسل كلمات طبعة ١٤٣٩ مع
تسلسل كلماتنا ثم يضع كلماتنا على سطورها (٧٧٬٤٣٣ كلمة، ٦٠٤ صفحة × ١٥ سطراً).
دقّة المحاذاة: تطابق تام في ٦٠٠ صفحة من ٦٠٤، والفرق في الباقي ٤ كلمات فقط

## ٨) زخارف أرقام الآيات

الإعدادات ← **زخرفة رقم الآية**: ٤٧ رسماً لعلامة الآية ۝ من مشروع
[quranpedia/ayah-markers](https://github.com/quranpedia/ayah-markers) (ترخيص OFL)،
مرسومة كـ SVG متعدد الطبقات، والرقم يوضع في مكانه الصحيح داخل كل زخرفة
(من `collection.json`: إحداثيات `cx, cy` وارتفاع صندوق الرقم).
الزخرفة الابتدائية = **٠١٢** (رسم Noto Sans Arabic)، ويمكن اختيار «رسم المصحف»
(﴿١﴾ كما يرسمه خط المصحف) أو أي زخرفة أخرى من القائمة. تعمل الزخارف مع الطبعتين وكل الخطوط،
وتتلوّن مع الوضع الليلي تلقائياً.
البيانات: `assets/ayah-markers.json` (٢١٠ ك.ب).

* التلوين يعمل على **أي خط** (بما فيه رسم المصحف)، ولا يقطع وصل الحروف (مُختبَر: عروض السطور متطابقة قبل/بعد التلوين).

## ١٠) ضبط السطور وتوسيطها

* **ضبط حقيقي (Justify) بلا تشويه للحروف**: الفراغ المتبقي يُوزَّع على المسافات **بين الكلمات**
  (`word-spacing`) فتبقى الحروف على شكلها الطبيعي في كل السطور؛ وما زاد عن حدّ الضغط أو التوسيع
  يُعالَج بمطّ/ضغط خفيف جداً. النتيجة (١٤٠٥): **٩١٪ من السطور بلا أي مطّ** (تحجيم ١٫٠٠٠)
  والباقي بين ٠٫٨٥ و٠٫٩٥، وتباعد الكلمات متساوٍ داخل السطر (٦٫٣ بكسل بين كل كلمتين).
* **تساوي الطرفين**: كل سطر يبدأ من الحافة اليمنى **وينتهي عند الحافة اليسرى نفسها** —
  مُختبَر على ٨٧ صفحة (١٬٢٥٣ سطراً في ١٤٠٥ و١٬٢٥٨ في ١٤٣٩): **أكبر فراغ = ٠ بكسل و٠ سطر خارج الضبط**.
  (كانت ١٤٠٥ تعتمد معامل قاعدة الرسم فتترك ٥–٣٤ بكسل، و١٤٣٩ كانت تترك السطور القصيرة بلا معالجة
  لأن `scrollWidth` يرجع عرض الحاوية إذا كان المحتوى أقصر منها.)
* القياس محصَّن ضد **التكبير**: التكبير مطبَّق كـ `transform: scale()`، فالأبعاد المقيسة
  بـ `getBoundingClientRect` تكون مكبَّرة؛ يُردّ القياس إلى مقياس التنسيق قبل المقارنة،
  والضبط صحيح عند ١٠٠٪ و١٢٠٪ و١٣٥٪ و١٦٠٪ و٢٠٠٪ (مُختبَر).
* **السطور القصيرة تُوسَّط** (آخر سورة، بسملة الافتتاح) كما في المصحف المطبوع.
* **البسملة الافتتاحية موسّطة دائماً** في طبعة ١٤٣٩.
* في طبعة ١٤٣٩ السطور تُوزَّع **بالتساوي على ارتفاع الصفحة** بلا فراغات كبيرة: الصفحات
  الافتتاحية (١ و٢ وما شابهها) كانت تترك ٧ أسطر فارغة في الأعلى، فصارت كلماتها مبسوطة على
  كامل الصفحة مع بقاء الزخرفة الافتتاحية.
* **عرض وجهين**: الأزواج ١-٢، ٣-٤، ٥-٦ … والصفحة الفردية على **اليمين**
  (الفاتحة يميناً، وأول صفحة من البقرة يساراً).

## ١١) لماذا لا تعمل روابط Google Drive؟

روابط مثل `https://drive.usercontent.google.com/download?id=…&export=download`
تُرجع ملفاً صوتياً صحيحاً (`content-type: audio/mpeg`، `accept-ranges: bytes`)،
لكن جوجل تُرسل معها ترويسة:

```
cross-origin-resource-policy: same-site
```

وهذه **تمنع المتصفح من تضمين الملف داخل صفحة من نطاق آخر** — فيفشل حتى `fetch()` الخطأ `net::ERR_FAILED`
وعنصر `<audio>` يرفع `MEDIA_ELEMENT_ERROR: Format error`. الرابط يعمل فقط إذا فتحته في تبويب مباشرة.
لا يوجد رابط من Drive يعمل بالتضمين (كل الأشكال `drive.google.com` و`docs.google.com` تئول إلى نفس الخادم).

**الحلول**:
1. ارفع الملفات على استضافة عادية تسمح بالتضمين (أي خادم ويب، GitHub Pages، Cloudflare R2، Firebase Storage، …)
   — الشرط: `Content-Type: audio/mpeg` + `Accept-Ranges: bytes` + بدون `Cross-Origin-Resource-Policy`.
2. أو نزّل الملف واستخدم زر **«ملف محلي»** في التطبيق.
3. التطبيق ينبّهك تلقائياً عند رابط Drive ويفتحه في تبويب جديد.

## ١٢) الخط الرقمي

اختيار «الخط الرقمي» يبدّل الخط إلى مكدّس خطوط عربية شائعة في الأنظمة
(`Noto Naskh Arabic`, `Traditional Arabic`, `Geeza Pro`, `Al Bayan`, `Segoe UI`, `Tahoma`, `Arial`).
وبما أن قاعدة الرسم (تقطيع السطور) محسوبة لخطوط المصحف فقط، يُعاد تقطيع كل صفحة آلياً:

1. تُقاس كل كلمة بعنصر مخفي **بنفس خط الصفحة تماماً** (لا بالـ canvas: قد يختار خطاً آخر).
2. يُحسب هدف تعبئة السطر ببحث ثنائي بحيث يملأ النص **نفس عدد السطور** المعهود في الصفحة
   (العنوان والبسملة سطرٌ خاصٌ كلٌّ منهما، ويُحفظ ترتيبهما — قد يأتي العنوان في وسط الصفحة).
3. يُضبط كل سطر بـ `justify` بين الكلمات كما في باقي الخطوط.
4. إن ضاق النص عن سطور الصفحة (خط عريض جداً) يُصغَّر قياس خط تلك الصفحة وحدها بما يكفي.

مُختبَر على ٣٦ صفحة: **لا سطر خارج الضبط ولا كلمة ناقصة**، وعدد السطور محفوظ (١٥، و٨ لصفحة الفاتحة).
